For RMMFB purposes, the current interpretation is therefore that this

## NTEC question

The left-hand / vertical-writing region is a useful test case for the
Nyquist Text Existence Criterion because it raises a distinction between:

1. evidence available in the image or crop itself, and
2. evidence supplied by surrounding images or object-level context.

The important experiment is to evaluate the relevant region from
`00021` *without* using `BnF_-_Ms-Lat-18554_00020.jpg` or other nearby
views.

Question:

> Does the image region itself contain enough recoverable
> writing-specific information that NTEC should **not disqualify it as
> text**, even when its contextual relationship to the manuscript is
> hidden?

Then evaluate the same observation with adjacent/context imagery
available, especially `BnF_-_Ms-Lat-18554_00020.jpg`.

The final NTEC write-up should explicitly report which of these outcomes
occurs:

- NTEC passes the region on image evidence alone.
- NTEC rejects or remains agnostic on the isolated region, but contextual
  imagery makes the presence of writing evident.
- NTEC still finds insufficient writing-specific evidence even with the
  contextual interpretation known.

This example should therefore be retained regardless of which outcome
the final NTEC formulation produces. It is useful specifically because
it tests whether NTEC is measuring **recoverable textual evidence in an
observation**, rather than merely inheriting an object-level judgment
that "this is a manuscript fragment."

## RMMFB / NTEC distinction

Do not use the RMMFB classification itself as the NTEC answer.

RMMFB is making an object/reuse judgment. NTEC should independently ask
whether the sampled visual observation contains enough information to
support the existence of writing.

This image is a useful matched example where those two questions may
come apart.
